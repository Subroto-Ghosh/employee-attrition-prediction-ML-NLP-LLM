# Project Scope

## Research Scope

This project evaluates employee attrition prediction from three related perspectives:

1. Classical machine learning for structured tabular data.
2. Transformer-based NLP modeling after converting tabular records into natural-language text.
3. Lightweight LLM-based modeling for the same prediction task.

## Evaluation Scope

The study considers predictive performance together with:

- Class-imbalance handling
- Hyperparameter tuning
- Ensemble learning
- Decision-threshold selection
- Explainability
- Text augmentation
- Ablation analysis

## Intended Use

The repository is intended for academic study, experimentation, reproducibility, and comparison of modeling approaches. It is not intended to provide an employment decision system for operational use.
