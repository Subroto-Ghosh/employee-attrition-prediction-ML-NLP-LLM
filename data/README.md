# Dataset Acquisition

This project uses the **IBM HR Analytics Employee Attrition & Performance** dataset.

The dataset is intentionally excluded from this repository because it is an externally sourced dataset and should be obtained in accordance with its applicable terms.

## Expected File

The notebooks expect the following CSV file:

```text
WA_Fn-UseC_-HR-Employee-Attrition.csv
```

After obtaining the dataset, place the CSV in the working directory used by the notebook.

## Dataset Statistics

- Records: 1,470
- Raw attributes: 35
- Target variable: `Attrition`
- Positive attrition cases: 237

## Source

IBM HR Analytics Employee Attrition & Performance dataset, available through Kaggle under the dataset page identified in the original project materials.

Please review the current dataset terms before redistribution or reuse.
